# CatToy 🐱 逗貓遊戲

給貓咪玩的平板／手機遊戲：螢幕上會有老鼠、小蟲、雷射點、小魚、羽毛跑來跑去，貓咪拍到就會吱吱叫、噴出彩色粒子並計分。

## 線上玩
👉 **https://timemap26-sudo.github.io/CatToy/**

用平板打開後，在瀏覽器選「加入主畫面」，就能像 App 一樣全螢幕開啟。

## 怎麼玩
1. 打開上面的網址（或直接用瀏覽器打開 `index.html`）。
2. 選擇玩具種類、數量、速度與音效，按「開始玩！」。
3. 把平板平放在地上讓貓咪追。
4. 長按右上角 ⚙︎ 2 秒回到選單（避免貓咪誤觸）。

## 特色
- 獵物會隨機停頓、抽動、躲到牆邊，拍歪了還會逃跑，模擬真實獵物行為
- 純 HTML + Canvas，無任何依賴，單一檔案
- 支援觸控、全螢幕、震動回饋與 Web Audio 音效
